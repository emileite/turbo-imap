    Thunderbird

    Como carregar as mensagens no Thunderbird

    Formato Mbox nativo

    Opção 1 — abrir direto nas Pastas Locais (recomendada)

    1. Feche o Thunderbird completamente.
    2. No Turbo IMAP, use como destino a pasta Mail\Local Folders do perfil.
    3. Mantenha um prefixo como TurboIMAP- para não sobrescrever pastas existentes.
    4. Execute o backup e abra o Thunderbird.
    5. As pastas aparecerão em Pastas locais como TurboIMAP-INBOX, TurboIMAP-Sent, etc.

    Opção 2 — exportar e importar depois

    1. Escolha uma pasta de backup comum como destino.
    2. Execute o backup para gerar os arquivos Mbox.
    3. No Thunderbird, instale a extensão ImportExportTools NG.
    4. Clique com o botão direito em Pastas locais.
    5. Escolha ImportExportTools NG > Importar arquivo mbox e selecione os arquivos.

    Feche o Thunderbird antes de gravar diretamente em Mail\Local Folders. A data final do filtro é inclusiva. Um guia completo também é salvo na pasta de destino como LEIA-ME-THUNDERBIRD.txt.

      Objetivo do aplicativo
      
            
      
              O Turbo IMAP é uma interface gráfica para simplificar a migração, o backup,
              a exportação, a importação, a limpeza e a auditoria de contas de e-mail que
              usam o protocolo IMAP.
            
      
            
      
              O IMAP (Internet Message Access Protocol) mantém as mensagens no servidor e
              sincroniza pastas, mensagens, anexos e estados de leitura entre vários
              dispositivos. Em uma migração entre provedores — por exemplo, de Gmail para
              Microsoft 365 — é preciso copiar a estrutura de pastas e preservar o conteúdo
              das caixas, evitando perda de mensagens e retrabalho.
            
      
            
      
              O aplicativo reúne os scripts Perl em formulários, valida os parâmetros, monta
              os comandos, executa cada ferramenta em um subprocesso, acompanha o progresso,
              grava logs e mantém as últimas configurações. Isso reduz erros manuais e torna
              operações longas mais seguras e rastreáveis, sem exigir que o usuário memorize
              dezenas de opções de linha de comando.
            
      
          
      

          
      
            
      Tecnologias utilizadas
      
            
        
              
      • Electron + Node.js — aplicativo desktop e execução dos processos.
        • 
              
      • Bulma CSS — interface responsiva e componentes visuais.
        • 
              
      • SQLite — configurações, credenciais protegidas e histórico local.
        • 
              
      • Strawberry Perl portátil — runtime incluído para executar os scripts no Windows.
        • 
              
      • child_process + IPC seguro — execução dos scripts e comunicação com a interface.
        •

      Origem dos scripts
      
            
      
              As operações de IMAP são executadas pela suíte open source
              rick-sanders-imap-tools, criada por Rick Sanders
              e disponível em github.com/rick-sanders/imap-tools. Os scripts
              Perl são mantidos separados da interface do aplicativo.

      Aviso importante
      
            
      
              As credenciais ficam armazenadas localmente. Ferramentas de limpeza e exclusão
              podem remover mensagens permanentemente. Quando disponível, mantenha o modo de
              teste ativado e faça um backup antes de operações destrutivas.

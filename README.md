# turbo-imap
O Turbo IMAP é um app desktop Windows (Electron) que usa os scripts rick-sanders-imap-tools para facilitar a migração, backup e gestão de e-mails. Com interface intuitiva em Bulma.io, ele salva credenciais via SQLite, exibe o progresso em tempo real, gera logs e permite retomar migrações pausadas sem a necessidade de usar o terminal.
